# Research

Status: active
Role: research evidence, bounded investigations, and reusable synthesis
Authority: analytical; non-normative
Lifecycle: retained; sources immutable/append-only where practical

## Belongs here
- captured or referenced source material
- bounded investigations
- reusable synthesis
- incumbent capability inventories before authoritative disposition

## Does not belong here
- accepted architectural requirements
- implementation code
- execution plans

## Standard substructure
- `sources/`
- `investigations/`
- `synthesis/`

## Promotion and routing
Research may inform a proposal or decision. Only accepted authority changes normative architecture or capability ownership.
