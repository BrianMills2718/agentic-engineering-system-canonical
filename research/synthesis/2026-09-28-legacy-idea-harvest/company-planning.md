## Failure lessons

1. **A lock AES would have added duplicated the workspace's claim system and lost data.** The cursor lease
   could not follow a sanctioned claim handover, and the cursor file was untracked, so worktree cleanup
   deleted it. That contradicted the skill's own promise that archiving never loses evidence. Evidence:
   commit `d9a7f11` (58 uses, average 3.3/5). Lesson: take ownership from the one existing registry, and
   make position durable by committing it.
2. **In-progress state merged into `main` deadlocked every later lane**, and the agent then called an
   internal fix "needs contributor review". Evidence: PMF-018 in `P/docs/PLANNING_METHOD_FEEDBACK.md`;
   `.company-planning/history/003c30ba00b1c94d-r4.json` (a `human_required` record waiting on an org-owner merge).
3. **A gate verified only on hand-built fixtures had 0 of 2 precision on real transcripts, and was reverted.**
   Replaying the "read SKILL.md without invoking it" trigger over 1,302 real transcripts found two firings,
   and neither was a real skip: one was an audit reading the skill, the other was the session that built the
   gate. Reading a procedure file cannot tell using it from writing it. Evidence: commit `2d6bf9b` (PR #180).
   Lesson: replay a proposed blocking rule over real history before shipping it.
4. **Finding a configured name is not the same as a live hook.** The Codex wiring check grepped the config
   for the hook name and reported a dead hook as ACTIVE. It was replaced by path resolution with
   `absent` / `broken`. Evidence: `.project-brain/truth.md` (PRs #187 and #188);
   `P/scripts/codex_gate_wiring_status.py`.
5. **A gate that blocks when its own input is unreadable takes down unrelated work.** A cursor with drifted
   schema blocked every stop in three repositories. Fix: warn loudly and do not block when the thing that
   failed is the gate's own input. Evidence: `.project-brain/truth.md` (PR #189). This refines "fail
   closed": fail closed on the governed decision, fail loudly on the gate's own input.
6. **The circuit breaker was built but never exercised in real use.** In 14 real cursors the repeated-failure
   cap and the ready-alternative switch never fired (highest `same_boundary_failures` = 1). The only
   non-complete ending was a `human_required` record that deadlocked. Evidence: `.company-planning/history/*.json`.
   Lesson: rate `circuit_break` and `switch` as tested, not observed. The human-boundary exit is the part that
   needed the most design.
7. **Enforcement measured mostly its own probes.** The ordinary-use cohort had 1 eligible episode out of the
   10 required; 15 of 16 retained receipts were operator controls. Evidence:
   `P/docs/evidence/2026-08-25-to-2026-09-01-ordinary-use-cohort.json` (status `incomplete`). Same shape as
   inside-success lesson B7.
8. **Correct routing prose was read and not followed.** The agent read `initiative-roadmap`,
   `bounded-design` and similar SKILL files 11 times after its last real invocation, even when asked "are we
   using living document skill?". Adding more routing prose cannot fix that failure. The fix was an
   agent-authored route declaration checked at Stop. Evidence:
   `P/docs/designs/enforcement/ROUTE_INVOCATION_ENFORCEMENT.md` (transcript `22be9465…`).
9. **Target drift before any reading happened.** Asked to roadmap the plugin, the agent roadmapped Hetzner
   and the second brain, and needed two corrections. Fix: an explicit target lock before wide investigation.
   Evidence: `P/docs/DOGFOOD_STATUS.md` §Fresh-Session Dogfood Failure 2026-07-25; `P/docs/evidence/target-lock/meta.json`.
10. **Current-truth inspection did not stop once the decision was resolved.** One run used 128,802 tokens and
    was interrupted without returning the frontier decision. Evidence: PMF-003.
11. **A migration contract hardened self-reported semantics too early.** V1 accepted `verified` without
    receipts, trusted asserted redirect booleans, and joined authority through free text and file paths.
    It was superseded by V2. Evidence: PMF-010 (and `P/contracts/planning-authority-migration.v2.schema.json`).
12. **Suppressing questions also suppressed the report** (the reason for idea 6). Evidence: `.project-brain/truth.md`, PR #191.
13. **A generalization claim was rejected three times and the rejections were kept.** WU005 was accepted
    only for its bounded synthetic scenario. Evidence: `P/docs/evidence/contributor-led-planning/solo/generalization-run.rejected.v{1,2,3}.json`,
    `eval-decision-signoff-final.md`.

## Not worth harvesting

- **The contributor-facing dashboard and projection stack** (`P/contracts/dashboard/*`, `P/scripts/dashboard_projection/`,
  `generated/`, `ui/`, the review-surface and project-review-projection contracts, Structurizr and
  semantic-domain experiments). These are Company Planning products for humans reviewing portfolios. Idea 18
  keeps the one reusable data rule.
- **The package-root resolver ritual in every SKILL.md** (inline Python that finds the snapshot under
  `plugins/cache`). It is plumbing specific to the plugin cache. Idea 14 keeps the principle.
- **Legacy `ManualExecutionAuthorizationV1` / `ManualCompletionDecisionV1` / `DeploymentAuthorizationV1`.**
  They are already marked legacy-only, and the `repository_autonomy` profile does not use them.
- **Session work closeout snapshot** (`P/docs/plans/50_session_work_closeout.md`). The workspace
  `AGENTS.md` closeout format already carries session goal, subgoals and delegated-work adoption. Nothing
  AES-specific to add.
- **The skill feedback telemetry hooks** (`skill_feedback_log.py` and related). They collect per-machine
  records only, and sharing them is an unresolved consent question (`.project-brain/state.md`).
- **Deploy-work-unit and Hetzner/Docker/Caddy references.** They are specific to a host.
- **Semantic kernel and planning-authority migration V2.** They are heavy, only fresh-verification-pending,
  and PMF-010 shows the first version hardened too early. Revisit only if AES needs to replace target
  authority across repositories.
