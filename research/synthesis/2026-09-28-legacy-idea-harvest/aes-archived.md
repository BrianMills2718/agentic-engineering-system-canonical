## Failure lessons

1. **Archive reason: an undeclared fork, not a failed idea.** The 2026-08-24 brief said "rewrite from a clean foundation". What happened was a second repository with an unrelated root. The old repo kept receiving roadmap, gates and handoffs while this one got all the code. Neither declared the other, and `PROJECT_GRAPH.json` listed only one, so an agent reported the *wrong* repo as retired. It was folded back with `--allow-unrelated-histories` on 2026-08-26. Evidence: `gh repo view BrianMills2718/aes` description ("Folded into BrianMills2718/agentic-engineering-system on 2026-08-26 (tag lineage/v2)"); `/home/brian/code/agentic-engineering-system` commit `e4c345d` body and merge `0aa88f8`; later cited as "one undeclared fork" in that repo's `b6955ee` (Decision 0013).
2. **The mission went missing in two days, and the roadmap was scored against a mechanism.** `docs/decisions/` was not carried into the rewrite, so the roadmap's outcome became "component 2 of thirteen stated as though it were the system". "A slice scored against itself always looks complete." Fix: the mission goes in a decision with supersession discipline, is added to `required_reading.defaults`, and the README table names unbuilt components instead of omitting them. Evidence: `docs/decisions/0006-...md`; roadmap "Revision, 2026-08-26"; `CONTEXT_ENGINEERING_...md` §6d. (This overlaps IS harvest B1, which is cited from the successor repo. The source is here.)
3. **CI never passed once: 37 runs, 37 failures, because a secret was never set.** So the suite, self-application and drift checks had never run on a runner. Once it got past step one, it surfaced 3 more failures that had never been visible, including a depth-1 clone breaking the audit-cadence check. "A control that has never passed is not a control anyone reads." Evidence: commit `804cc8b` body.
4. **A lesson recorded and ungated fired zero times, twice in two days.** The GIT_* fixture leak recorded in `dodaf` on 2026-08-21 was re-created here on 2026-08-26. A `git checkout` mistake destroyed uncommitted work twice in one session, an hour after it was written down. Evidence: `docs/AUDITS.md` §Repeats; `scripts/audit_cadence.py` docstring; commit `d802ec2`.
5. **The first version of every "honesty" mechanism reproduced the failure it was built to prevent.** The scope audit reported clean without running (`5482eef`). The HEAD stamp was always stale (`src/aes/revision.py`). A leaked loop variable printed one invariant's coupling under another's name, and only crashed in CI where the order differed: "a wrong line that reads correctly is the worse failure". The cadence control was an existence check that a mutation survived (`d802ec2`). Evidence: `CONTEXT_ENGINEERING_...md` §6c; the commits named. Lesson: test each state of a status surface against a case that should produce it (see #15).
6. **Before the rewrite, the typed evidence contract could not express failure.** `negative_control_observed: Literal[True]` made "negative control observed" an artifact of the type. The one verification tool that falsified the core premise (enforced-group violation rate 3.27% against 0.95% unenforced, 3.4 times worse) had been retired to `v1/`. Evidence: `docs/designs/AES_REWRITE_BRIEF_2026-08-24.md` §"Why not retrofit".
7. **Proven only on a proxy route.** The suite showed 91 of 92 passing from the root on the same revision that corrupted a checkout under the hook. Evidence: `docs/AUDITS.md` A2.
8. **Coverage stayed tiny, and whether agents complied was never observed.** Gate reach was 5 of 572 files. "The gate is observed to fire. Reading and compliance remain unobserved." Evidence: `docs/roadmap/2026-08-25-aes-initiative-roadmap.md` §"Progress, separated"; g1 readout §"What this does not establish".
