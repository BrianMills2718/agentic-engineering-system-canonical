`docs/planning/planning-package.json`. Source: Brian, 2026-11-23: "i approve", item (c) of

## Steps

template (steps 1, 2, 5); then the proof (step 6). New helpers in `src/lockstep/` are private (`_name`): AES's own
layout rows declare no exports, so a new public function there is refused by its own edit hook.

   so copies carry no AES IDs. Spec `lockstep-checks`.
1. Done (spec `portable-template`, archived change `2026-11-23-template-ships-layout`). Template `lockstep.yaml`, rendered only by `copier copy`: `copier.yml` gets
   `_exclude: ["{% if _copier_operation == 'update' %}lockstep.yaml{% endif %}"]` (tried on copier 9.19.1: a

4. `docs/links.json`: one `file` node per layout row and one `symbol` node per declared export, each with `state`

## Design review (departures from the settled documents)

- Rows for the template's three starter files are written by hand, not laid out from an accepted plan; they are
  the starter, not a plan.
- `tests/` is not governed: DESIGN names tests in rows but does not say tests must be refused when unplanned.
  Inferred by agent: hidden acceptance tests are copied into `tests/` by `run-plan`, which a governed `tests/`
  would refuse.
- "A person accepts the plan" stays the commit of the plan (as in run-plan today); no separate accept command.
  Same as minimal core; not in DESIGN.
- Codex has no refusing hook; the whole-tree check in `make check` is its gate (already the stated position in
  back-on-design).
- Only `.py` files are laid out, and a row's success criteria are its requirements' scenarios (as `lockstep
  layout` writes today); DESIGN says "the planned files" without naming types.
- The template writes `lockstep.yaml` itself; `lockstep init` stays the route for an existing repository.
- Cold review (2026-11-23, plan without this section): found the `_skip_if_exists` gap, the missing cog blocks,
  the docstring line step 0 would have read, the empty `HEAD` comparison and the unsaved evidence; all folded in
  above. It also listed the plan-commit-as-acceptance departure, which stays as written.
