Agent feedback loop: start here

Agents end each reply with a short Feedback section. Every night those lines are collected. Repeated problems are grouped and analysed, and a fix the evidence supports is handed to a daily agent that puts it into a rule or check. A daily counter then checks whether the problem stopped. This page is the map: what runs, where each document is, and what is still open. Updated 12 October 2026.

One example: on 11 October an agent noted that a gate's block message pointed to an outdated place. The collector turned that line into a record that night, filed it, and it joined a problem on Sunday. When a problem like this is seen 11 times and then fixed (AES #552), the counter shows 0 sightings since.

Programs run from ~/.hive-brain/aes, a copy of AES main. Outputs (private, never committed) are in ~/projects/data/feedback-collector/. Each job's command, outputs, failure behavior and how to rerun it: jobs guide.
