This is the progressive-disclosure front door for the canonical AES convergence project. It is a derived navigation/synthesis surface, not a native authority.

## Current orientation

**Target:** one coherent engineering system in which accepted intent produces explicit gaps; Company Planning derives execution-ready design; ACA resolves reusable capabilities before local implementation; Enforced Planning governs execution; policy keeps work aligned with recovery/change paths; evidence re-characterizes the exact implemented revision; gaps are recomputed; and useful observations strengthen future capability and policy knowledge.

**Current:** repository bootstrap only. The repo contract, navigation, normative system boundary, lineage decision, and incumbent capability inventory exist. No implementation root or first execution plan has been accepted.

**Gap:** the target system is largely unrealized in this repository. The first real gap set must be derived from the accepted target versus this unrealized state rather than hand-written as a substitute for characterization.

**Plan:** `UNPLANNED` by design. The next planning action is a Company Planning pass that dispositions the initial gaps, selects one authentic external-consumer vertical, performs ACA capability resolution, and emits the first target implementation/verification topology and execution contract.
