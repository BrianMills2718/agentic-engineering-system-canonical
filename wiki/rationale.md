## Reasons stated in design documents

- Decision 0009 retires `aes` per repository rather than all at once because a sweep across twelve idle repositories goes against adopting when changed; keeping it would leave two systems for one job. [docs/decisions/0009-aes-and-lockstep-fate.md:44-47](https://github.com/BrianMills2718/code2-workspace/blob/b8b523d7ec59f54248dac2d7a780441b787d6921/docs/decisions/0009-aes-and-lockstep-fate.md#L44-L47)
- Lockstep is merged into `code2check` in stages because retiring it now would break the lifelike hook and the Team-Brains gate. [docs/decisions/0009-aes-and-lockstep-fate.md:51-53](https://github.com/BrianMills2718/code2-workspace/blob/b8b523d7ec59f54248dac2d7a780441b787d6921/docs/decisions/0009-aes-and-lockstep-fate.md#L51-L53)
- The code2 redirect (2026-10-13): Brian asked for off-the-shelf tools instead of his own system, with every check finishing in seconds. [proposals/code2-ecosystem/PLAN.md:21-27](../proposals/code2-ecosystem/PLAN.md#L21-L27)
- The commit rule was turned off because enforcement made trivial agent tasks take an hour. [.project-brain/now.md:56-58](../.project-brain/now.md#L56-L58)
- v0.2 treated hooks as invocation adapters, not enforcement, after all 67 v0.2 proposal-branch commits bypassed v0.1 governance as `[Unplanned]`. [docs/decisions/0010-greenfield-v0.2-accepted.md:153-156](../docs/decisions/0010-greenfield-v0.2-accepted.md#L153-L156)
- v0.2 claimed no value beyond mechanism: both fresh-agent context A/Bs could not tell the packet arm from the repository-only arm. [docs/decisions/0010-greenfield-v0.2-accepted.md:160-164](../docs/decisions/0010-greenfield-v0.2-accepted.md#L160-L164)
- One target file was chosen first for one atomic snapshot and no cross-file sync, accepting that it could grow large. [docs/architecture/greenfield-v0.2/13-greenfield-materialization.md:122-140](../docs/architecture/greenfield-v0.2/13-greenfield-materialization.md#L122-L140)
- Project brains live as Markdown in each repository's `.project-brain/`; gbrain, Hermes, mem0, Letta, Cognee and Paperclip issue documents were rejected. [.project-brain/truth.md:7-17](../.project-brain/truth.md#L7-L17)
- The weekly learning-loop run is a systemd timer, not a Paperclip routine, because a fixed script needs no agent and the timer keeps running when agents are down. [.project-brain/truth.md:21-23](../.project-brain/truth.md#L21-L23)
- Utility and conformance are kept apart: automated green cannot override a stakeholder saying the result is low-value. [docs/architecture/HUMAN_OBSERVABLE_DELIVERY.md:252-268](../docs/architecture/HUMAN_OBSERVABLE_DELIVERY.md#L252-L268)
