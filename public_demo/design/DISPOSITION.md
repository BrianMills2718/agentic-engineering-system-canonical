# Representation Router disposition (2026-09-30)

Use cases run through the router: `greeter`, `self`, `owngoal` (`*.rec.json` here). Built to the agent's composition plan:

- Tiny project: four-step state track plus a commit timeline with the test result pinned to its commit (router's primary was a scroll explainer; overridden because one-click steps show the verdict changing, which is the point). Stale pins are hatched with the reason and the commit that edited the file is tagged.
- AES on itself: one row per criterion with a freshness-split bar, expandable to requirements and recorded runs (router's 9x62 grid exceeded its density budget and fails on phones).
- Own goal: goal -> criteria -> requirement -> how proven tree; a refusal is attached to the requirement at fault. AI-drafted nodes are dashed and tagged.
- Standing is shape + word + colour (Proven / Not proven yet / Disproven); AES's own terms appear in the "Show the commands" view.
- Live vs recorded is stated on every result.
